### English

**Komga Toolkit automation — extended (admin)**

The Toolkit automation screen (Settings → Admin → Komga Toolkit) gains two more
sources and a clearer layout.

- Six functions across four sources: upcoming-releases and release-tracking via
  Manga News / MangaBaka, plus volume-tracking via Bedetheque and issue-tracking
  via ComicVine.
- The screen is now grouped by perimeter (Mangas / BD / Comics). Each category
  is bound to a Komga library — auto-matched by name, editable — and every
  function runs only against its category's library.
- One tap per function: it analyses and applies in the same server job (after a
  confirmation), then shows the summary. The work runs in the background, so you
  can leave the screen and come back; a job can run up to 45 minutes.
- When a function is unavailable, the button now says why (source not ready on
  the Toolkit server — Bedetheque CSV not loaded, ComicVine key missing).
- Android system notification when a job finishes, with the notification
  permission requested on first launch. Buttons to test connectivity and open
  the Toolkit web UI.

Optional and personal as before: with no URL/token set, Kora contacts no server.

### Français

**Automatisation Komga Toolkit — étendue (admin)**

L'écran d'automatisation Toolkit (Réglages → Admin → Komga Toolkit) gagne deux
sources supplémentaires et une présentation plus claire.

- Six fonctions sur quatre sources : prochaines sorties et suivi des sorties via
  Manga News / MangaBaka, plus suivi des tomes via Bedetheque et suivi des
  tomes/issues via ComicVine.
- L'écran est désormais groupé par périmètre (Mangas / BD / Comics). Chaque
  catégorie est liée à une bibliothèque Komga — associée automatiquement par le
  nom, modifiable — et chaque fonction ne s'exécute que sur la bibliothèque de
  sa catégorie.
- Un seul appui par fonction : elle analyse et applique dans la même tâche
  serveur (après confirmation), puis affiche le bilan. Le travail tourne en
  arrière-plan, tu peux quitter l'écran et revenir ; une tâche peut durer
  jusqu'à 45 minutes.
- Quand une fonction est indisponible, le bouton indique désormais pourquoi
  (source non prête côté Toolkit — CSV Bedetheque non chargé, clé ComicVine
  manquante).
- Notification système Android à la fin d'une tâche, avec la permission de
  notification demandée au premier lancement. Boutons pour tester la connexion
  et ouvrir le WebUI de Toolkit.

Optionnel et personnel comme avant : sans URL ni jeton, Kora ne contacte aucun
serveur.
